# AdVantage MMM - Ridge and Bayesian Meridian

AdVantage is an end-to-end Marketing Mix Model project for weekly spend across
TikTok, Facebook, and Google Ads. The original Ridge regression pipeline is
kept intact, and this version adds Google's open-source Meridian library for a
Bayesian MMM with posterior uncertainty.

## Data

`data/marketing_mix.csv` contains 200 weekly observations from 2018-01-07 to
2021-10-31:

- TikTok spend
- Facebook spend
- Google Ads spend
- Sales

`data/meridian_input.csv` is the Meridian-ready version generated by
`src/meridian_pipeline.py`. Because the raw project only has spend, not
impressions, clicks, reach, or frequency, each channel's spend is duplicated as:

- media execution proxy: `*_media`
- media spend: `*_spend`

That proxy is a practical workaround, not a substitute for real exposure data.

## Methods

### Ridge Regression

The original model in `src/mmm_pipeline.py` is unchanged. It uses:

1. EDA charts and channel correlation checks.
2. Manual geometric adstock and Hill-style saturation transforms.
3. Ridge regression with trend and seasonality controls.
4. A time-based 80/20 train/test split.
5. Point estimates for channel contribution, ROI, response curves, and budget
   recommendation.

Ridge results from the existing run:

|---|---:|

| Test MAPE | 4.7% |

### Bayesian Meridian

The new model in `src/meridian_pipeline.py` uses Meridian's built-in Bayesian
MMM machinery:

- Meridian geometric adstock.
- Meridian Hill saturation.
- ROI prior by media channel.
- National model with trend, annual sine, and annual cosine controls.
- MCMC posterior sampling with NUTS.
- Posterior mean and 90% credible intervals for contribution, ROI, and
  response curves.

Model settings used for the committed results:

## Ridge vs Meridian

Both methods agree on the ROI ranking:

1. Google Ads highest ROI.
2. TikTok second.
3. Facebook lowest ROI.

They do not agree on the size of the effects. Meridian estimates much larger
incremental contribution and ROI than the Ridge point-estimate model. That is
not something to hide: it reflects different model assumptions, the explicit
ROI prior, and Meridian's built-in adstock/saturation treatment. In an
interview, the safest explanation is that the directional ranking is consistent,
but the magnitude should be validated with incrementality evidence before
making large budget decisions.

## Running

Use Python 3.12. Meridian 1.7.0 is version-sensitive and should not be installed
into Python 3.14.

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python src/mmm_pipeline.py
.venv/Scripts/python src/meridian_pipeline.py
.venv/Scripts/python -m streamlit run app.py
```

On macOS/Linux, replace `.venv/Scripts/python` with `.venv/bin/python`.

## Honest Limitations

- This is still an observational MMM, not a randomized experiment. It estimates
  association after controls and model structure. It should be validated against
  geo-holdouts, lift tests, or another incrementality experiment before being
  treated as causal.
- The Meridian credible intervals are conditional on the model and priors. They
  are not magic truth intervals. The ROI prior used here is explicit:
  LogNormal parameterized to mean 0.45 and sd 0.45 per channel.
- Spend is used as a proxy for media execution because impressions, clicks,
  reach, and frequency are unavailable. This limits how literally the response
  curves should be interpreted.
- The sample has 200 weekly observations and only national-level data. That is
  modest for a Bayesian MMM with adstock and saturation.
- Ridge and Meridian agree on ROI ranking, but Meridian estimates larger effect
  sizes. Treat that as a modeling disagreement that needs external validation,
  not as proof that the larger numbers are correct.

## Extending This

- Replace spend-as-execution with impressions, clicks, reach, and frequency if
  those become available.
- Add price, promotion, competitor activity, macro variables, and holidays as
  controls.
- Use geo-level data if available so Meridian can estimate geographic variation
  rather than a single national curve.
- Calibrate or validate the model with real incrementality tests.
